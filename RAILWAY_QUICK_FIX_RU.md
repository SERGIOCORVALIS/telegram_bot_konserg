# 🚨 БЫСТРОЕ ИСПРАВЛЕНИЕ: Добавление переменных окружения на Railway

## Проблема
```
RuntimeError: Переменные среды обязательны: TELEGRAM_BOT_TOKEN
Ошибка 401 (Unauthorized)
```

**Причина:** На Railway не добавлены переменные окружения.

## ✅ Решение за 5 минут

### Шаг 1: Откройте Railway
1. Перейдите на [railway.app](https://railway.app)
2. Войдите в аккаунт
3. Откройте ваш проект

### Шаг 2: Откройте сервис
- Нажмите на ваш **сервис** (обычно называется "worker" или именем проекта)
- Вы увидите вкладки: **Deployments**, **Metrics**, **Logs**, **Variables**, **Settings**

### Шаг 3: Перейдите на вкладку Variables
- Нажмите на вкладку **"Variables"**
- Вы увидите список переменных (скорее всего пустой)

### Шаг 4: Добавьте переменные
Нажмите кнопку **"+ New Variable"** и добавьте каждую переменную:

#### ⚠️ ОБЯЗАТЕЛЬНО (минимум для запуска):

**1. TELEGRAM_BOT_TOKEN**
- **Key:** `TELEGRAM_BOT_TOKEN`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

**2. OPENROUTER_API_KEY** (можно использовать дефолтные ключи из кода, но лучше добавить)
- **Key:** `OPENROUTER_API_KEY`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

#### 📋 РЕКОМЕНДУЕТСЯ (для стабильной работы):

**3. OPENROUTER_API_KEY_1**
- **Key:** `OPENROUTER_API_KEY_1`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

**4. OPENROUTER_API_KEY_2**
- **Key:** `OPENROUTER_API_KEY_2`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

**5. OPENROUTER_API_KEY_3**
- **Key:** `OPENROUTER_API_KEY_3`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

**6. OPENROUTER_API_KEY_4**
- **Key:** `OPENROUTER_API_KEY_4`
- **Value:** `YOUR_SECRET_HERE`
- Нажмите **"Add"**

#### 🔧 ОПЦИОНАЛЬНО:

**7. APP_NAME**
- **Key:** `APP_NAME`
- **Value:** `AI Assistant Bot`
- Нажмите **"Add"**

**8. APP_PUBLIC_URL** (замените на ваш реальный URL из Railway)
- **Key:** `APP_PUBLIC_URL`
- **Value:** `https://your-project-name.up.railway.app`
- Нажмите **"Add"**

### Шаг 5: Проверка
После добавления всех переменных:

1. **Проверьте список** - вы должны видеть все добавленные переменные в списке
2. **Подождите 10-30 секунд** - Railway автоматически перезапустит сервис
3. **Откройте вкладку Logs** - вы должны увидеть:
   ```
   Starting bot polling
   Loaded X API keys and Y models
   ```
   ✅ **Если видите эти сообщения - бот работает!**

### Шаг 6: Тест
1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Бот должен ответить! 🎉

## 🔍 Если ошибка 401 сохраняется

Ошибка 401 обычно означает проблему с аутентификацией. Проверьте:

1. **Токен Telegram правильный?**
   - Формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
   - Без пробелов и кавычек
   - Получите новый токен от [@BotFather](https://t.me/BotFather) если нужно

2. **Переменные добавлены в правильный сервис?**
   - Убедитесь, что добавили переменные в сервис, который запускает бота (не в базу данных или другой сервис)

3. **Перезапустите сервис вручную:**
   - Нажмите три точки (⋮) рядом с сервисом → **"Restart"**

4. **Проверьте тип сервиса:**
   - Перейдите в **Settings** → Убедитесь, что **Service Type** = `Worker` (не Web Service)

## ⚠️ Важные замечания

- ✅ **Имена переменных чувствительны к регистру:** `TELEGRAM_BOT_TOKEN` ≠ `telegram_bot_token`
- ✅ **Без пробелов:** Убедитесь, что нет пробелов до/после имени или значения
- ✅ **Railway перезапускает автоматически:** После добавления переменных ждите 10-30 секунд
